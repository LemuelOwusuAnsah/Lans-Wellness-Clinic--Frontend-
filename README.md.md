# Lans Wellness Clinic (Frontend)

A modern, JavaScript-driven frontend for a wellness clinic website. Features dynamic content rendering, dark/light mode, and PWA support.

## Overview

Lans Wellness Clinic is a fully responsive, single-page application built with vanilla JavaScript. All content is loaded dynamically from JavaScript, making it easy to update and maintain. The design features a clean medical aesthetic with dark/light mode support and PWA capabilities.

## Features

- Fully dynamic content loaded from JavaScript
- Dark/Light mode toggle with localStorage persistence
- PWA support (installable, offline-ready)
- Filterable clinical pathways
- Testimonial carousel
- Booking modal with form validation
- Responsive design for all devices
- No hardcoded HTML content (all rendered via JS)
- Glass-morphism UI design
